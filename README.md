# MoodTunes

A viral web app that lets users track their daily mood through music. Each day, users select their current mood and receive a personalized song recommendation. The app creates beautiful, shareable 'mood calendars' showing their emotional journey through music.

Key Features:
- Daily mood check-in with expressive emoji selector
- AI-powered music recommendations based on mood
- Beautiful, shareable monthly mood calendars
- Streak tracking and social sharing
- Progressive Web App support

Tech Stack:
- HTML5, CSS3, JavaScript
- Web Audio API for music previews
- LocalStorage for offline support
- Responsive design
